# Thành phần dùng chung

TV1 điều phối component dùng chung khi xây UI chính thức; từng thành viên có thể đề xuất qua PR. Figma chưa truy cập được nên chưa chọn token hoặc xây button, input, badge, navbar/footer theo thiết kế. API client hiện nằm ở `lib/api.ts`, không thuộc thư mục UI. Component riêng của chức năng đặt trong `features/` tương ứng, không đưa tất cả vào đây.
