# opportunities

Trang chủ, Hub cơ hội, tìm kiếm/lọc, phân trang và chi tiết; chưa triển khai.

Phụ trách theo phân công mới nhất: **TV1**, cả frontend và backend tương ứng.

Chỉ thêm component, hook và lời gọi API khi bắt đầu chức năng. Đọc [quy trình nhóm](../../../../docs/team-workflow.md); không tạo route giả hoặc dữ liệu cá nhân để giữ chỗ.
