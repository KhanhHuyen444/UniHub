# auth

Đăng nhập Google và trạng thái xác thực; chưa triển khai. Hợp đồng chung: [auth-api-contract.md](../../../../docs/auth-api-contract.md).

TV1 làm nền auth/RBAC backend trước; **TV2 tiếp quản cùng auth module và hoàn thiện UI/session**, không tạo cơ chế xác thực khác. Chưa gán tên người hoặc deadline.

Chỉ thêm component, hook và lời gọi API khi bắt đầu chức năng. Đọc [quy trình nhóm](../../../../docs/team-workflow.md); không tạo route giả hoặc dữ liệu cá nhân để giữ chỗ.
