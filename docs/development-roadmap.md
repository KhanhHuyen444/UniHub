## Trạng thái và phụ thuộc còn lại

- Bốn quyết định nghiệp vụ §7.A và 13 nhóm kỹ thuật §7.B trong api-contracts.md đã được leader chốt. Cross-review phát hiện một lựa chọn nghiệp vụ mới về scoring Major/Skill Closed cho recommendations; contract đó và code recommendations chờ leader quyết định tại §10.
- Auth migration is absent from main though Chapter 4 PDF has google_sub/auth_sessions. This does not block documentation; it blocks running auth against real DB until a separate schema/migration/GRANT PR is reviewed and applied.
- Current Ch4 PDF omits deadline metadata already in main migration. Sync the report in a separate report change; do not mutate applied SQL.
- Course environment Node/MySQL support still needs verification before members use actual database. Do not assume a restriction.
- Figma Page 3 was read via the design handoff zip; detail page uses supplied Public screenshots. Measurements inferred from screenshots remain estimates.
- A design/report PDF revision is group-owned; this task records exact edits, not updates the PDFs.

## Completion evidence

- Scaffold pass does not prove API, database or login behavior.
- A module is implemented only with its routes/UI, permissions/data tests and integration evidence on the intended environment.
- Performance NFR requires load measurement; unit/integration passes alone do not establish it.
- Hosting/deployment is a separate task.
