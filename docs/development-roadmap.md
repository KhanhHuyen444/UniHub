## Completion evidence

- Scaffold pass does not prove API, database or login behavior.
- A module is implemented only with its routes/UI, permissions/data tests and integration evidence on the intended environment.
- Performance NFR requires load measurement; unit/integration passes alone do not establish it.
- Hosting/deployment is a separate task.
