# users

**Chưa triển khai.** Hồ sơ Student và Admin quản lý tài khoản/role. Contracts: [profile](../../../../docs/profile-api-contract.md) và [Admin users](../../../../docs/admin-users-api-contract.md).

Phụ trách: **TV2**, tiếp quản nền auth/RBAC backend do TV1 làm trước. Chưa gán tên người hoặc deadline.

Khi làm chức năng, bắt đầu bằng route/controller/service trong module này theo nhu cầu thực tế; chưa tạo code rỗng hoặc endpoint giả. Chỉ backend truy cập MySQL. Theo [quy trình nhóm](../../../../docs/team-workflow.md) và [quy ước API](../../../../docs/api-conventions.md).
