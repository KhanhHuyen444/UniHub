# activity-logs

**Chưa triển khai.** Cơ chế ghi nhật ký dùng chung; TV1/TV2/TV3 ghi log cho thao tác quản trị họ sở hữu. Quy tắc: [activity-logs-contract.md](../../../../docs/activity-logs-contract.md).

Phụ trách dự kiến: **TV5; phối hợp TV1**. Chưa gán tên người hoặc deadline.

Khi làm chức năng, bắt đầu bằng route/controller/service trong module này theo nhu cầu thực tế; chưa tạo code rỗng hoặc endpoint giả. Chỉ backend truy cập MySQL. Theo [quy trình nhóm](../../../../docs/team-workflow.md) và [quy ước API](../../../../docs/api-conventions.md).
